# Campus Events

**Направление:** Web Development
**Дополнительное направление:** Product Design
**Уровень сложности:** Начальный / средний
**Срок:** 1–2 недели

Веб-сервис, который собирает мероприятия колледжа в одном месте и предоставляет доступ к ним через понятный интерфейс. Может выступать пользовательским контуром для data-проекта College Events Intelligence.

## Проблема

Информация о мероприятиях колледжа распределена по нескольким источникам: сообщения в чатах, объявления, социальные сети и доски. Студент вынужден следить за разными каналами, чтобы не пропустить важное событие. При этом:

- непонятно, какие мероприятия проходят на этой неделе;
- сложно быстро найти дату, время и место события;
- у мероприятия часто нет единой карточки с подробностями;
- источникам не доверяют, потому что информация быстро устаревает;
- нет способа зафиксировать интерес к событию.

В результате подходящее мероприятие легко пропустить, а поиск актуальной информации отнимает время.

## Задача

Создать веб-сервис, в котором мероприятия собраны в одном месте и доступны через понятный интерфейс. Пользователь должен быстро найти событие, понять, когда и где оно пройдёт, и при желании сохранить его.

## Описание

Campus Events — веб-продукт, который решает задачу упорядочивания информации о мероприятиях. Пользователь открывает сервис и видит актуальные события в виде единого списка или сетки карточек. По каждому событию доступна карточка со всеми ключевыми данными.

Архитектура продукта строится вокруг модели данных события. Участник должен самостоятельно решить, какие поля необходимы, как устроена структура приложения и как интерфейс связан с логикой хранения.

В самостоятельной (не интегрированной) версии мероприятия могут добавляться вручную через интерфейс. При интеграции с [[College Events Intelligence - Мероприятия и аналитика|College Events Intelligence]] данные поступают автоматически из структурированного события-контура.

Поток данных продукта:

`Интерфейс → Форма / Data Interface → Модель события → Хранилище → Список → Карточка`

Главная ценность проекта — не просто страница со списком, а продуманный законченный пользовательский продукт, которым реально пользуются.

## Минимальные требования

- отображение списка мероприятий;
- отдельная карточка каждого мероприятия;
- указание даты, времени и места проведения;
- возможность добавлять новые мероприятия;
- корректное отображение на компьютере и смартфоне;
- доступ к сервису другого пользователя.

## Возможное развитие

- **Level 2 — Категории:** мероприятия разделяются по категориям (учебные · спортивные · технологические · культурные · карьерные); фильтрация списка по категории;
- **Level 3 — Поиск и фильтрация:** текстовый поиск по названию и описанию; фильтры по дате, категории и месту;
- **Level 4 — Регистрация и интерес:** пользователь может зафиксировать интерес к событию или зарегистрироваться; сервис показывает количество участников;
- **Level 5 — Календарное представление:** события отображаются в календаре; видна загруженность недели;
- **Level 6 — Уведомления:** напоминания «за 1 час до начала», «за день», «новое событие в выбранной категории»;
- **Level 7 — Персональные рекомендации:** сервис учитывает интересы пользователя и подсказывает релевантные события;
- **Level 8 — Административный интерфейс:** отдельная роль, позволяющая модерировать события и управлять отображением.

## Интеграция с College Events Intelligence

Campus Events может выступать пользовательским интерфейсом для data-проекта [[College Events Intelligence - Мероприятия и аналитика|College Events Intelligence]] (Level 5). В этой связке:

- **College Events Intelligence** отвечает за сбор, AI Extraction, нормализацию, хранение и аналитику событий (формирует Structured Events Dataset + Events API / Data Interface);
- **Campus Events** отвечает за пользовательский интерфейс: просмотр событий, карточки мероприятий, поиск, фильтрацию, мобильный UX.

Схема: `Sources → College Events Intelligence → Structured Events Dataset → Events API / Data Interface → Campus Events → Student`.

Это позволяет двум разным командам MINILAB работать над частями одной системы.

## Оборудование и инструменты

Компьютер, браузер, редактор/среда разработки, AI-кодовый ассистент. Конкретные технологии реализации участник выбирает самостоятельно.

## Что предстоит изучить

- из каких частей состоит веб-приложение (frontend / backend / хранилище);
- модель данных мероприятия;
- как пользователь взаимодействует с интерфейсом;
- как приложение хранит и получает данные;
- как связаны интерфейс и логика приложения;
- адаптивный дизайн;
- формы и валидация пользовательского ввода;
- публикация веб-продукта и деплой;
- при интеграции — работа с внешним Data Interface / API.

Ключевая новая концепция — разграничение интерфейса, модели данных и источника данных: продукт должен работать даже тогда, когда источник данных изменяется, при условии сохранения контракта данных.

## Полученные навыки

Проектирование веб-продукта, работа с пользовательским интерфейсом, моделирование данных, клиент-серверное мышление, адаптивный дизайн, формы и валидация, тестирование пользовательских сценариев, AI-assisted development, публикация продукта. При интеграции с College Events Intelligence — первый практический опыт разделения продукта на data-контур (backend) и UI-контур (frontend).

## Результат

Работающий веб-сервис мероприятий, которым можно пользоваться с компьютера и смартфона. При интеграции с College Events Intelligence сервис получает структурированные данные о мероприятиях, сформированные data-контуром, и не требует ручного ввода.

## Критерии готовности

Проект считается завершённым, если:
- пользователь видит список мероприятий;
- карточка события корректно отображает дату, время, место и описание;
- новое мероприятие можно добавить через интерфейс;
- приложением можно пользоваться с телефона и компьютера;
- сервис доступен другому человеку;
- участник способен объяснить модель данных и путь данных внутри системы.

Для интегрированной версии дополнительно:
- существует стабильный интерфейс получения событий;
- данные, добавленные в College Events Intelligence, отображаются в Campus Events без ручного дублирования;
- изменение данных в data-контуре отражается в интерфейсе.

## Demo Day

Создать тестовое мероприятие вживую (или показать событие из College Events Intelligence), показать пользовательский сценарий открытия карточки, работу на телефоне и выбрать направление дальнейшего развития. При совместной демонстрации с College Events Intelligence показать один и тот же путь данных глазами аналитика и глазами студента.
