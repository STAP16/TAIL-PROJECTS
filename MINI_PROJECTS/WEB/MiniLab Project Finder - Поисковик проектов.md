# MiniLab Project Finder - Поисковик проектов

**Направление:** Web Development
**Дополнительное направление:** Product / Recommendation Systems
**Уровень сложности:** Начальный / средний
**Срок:** 2 недели

## Проблема

По мере развития MINILAB библиотека MiniProjects может содержать десятки проектов разных направлений и сложности.

Новичок открывает каталог и видит десятки проектов разных направлений, но ещё не знает достаточно об инженерных направлениях, чтобы понять, что подходит именно ему. Простой список проектов плохо решает проблему выбора.

## Задача

Создать веб-сервис, который помогает участнику MINILAB подобрать подходящий MiniProject на основании его интересов, опыта и доступных ресурсов.

## Описание

При первом запуске сервис задаёт участнику несколько вопросов (интересы, опыт программирования, желаемый результат, готовность работать с AI, доступное время, индивидуально или в команде). После прохождения небольшого опроса система анализирует ответы и предлагает несколько подходящих MiniProjects с объяснением выбора.

Важная часть проекта: участнику не выдаётся готовый алгоритм рекомендации. Команда должна сама спроектировать небольшую recommendation model: какие свойства описывают MiniProject, какие вопросы задавать, как ответы связаны с проектами и почему система рекомендует один проект выше другого.

## Минимальные требования

- содержать каталог MiniProjects;
- отображать карточки проектов;
- позволять просматривать проекты по направлениям;
- проводить небольшой опрос участника;
- учитывать несколько характеристик пользователя;
- предлагать несколько подходящих проектов;
- объяснять хотя бы на базовом уровне причину рекомендации;
- позволять открыть полную карточку выбранного проекта.

Минимальная версия не требует использования AI. Рекомендации могут строиться на детерминированной логике.

## Возможное развитие

- **Level 2 — Фильтры:** ручной поиск по Track → сложность → срок → оборудование → формат работы;
- **Level 3 — Recommendation Score:** расчёт соответствия для каждого проекта по самостоятельно определённой модели;
- **Level 4 — Explainability:** объяснение рекомендации человекочитаемым текстом, а не только процентом;
- **Level 5 — AI:** LLM превращает свободный текст в структурированные предпочтения, recommendation engine выбирает проекты (LLM — лишь один компонент архитектуры);
- **Level 6 — Реальная инфраструктура MINILAB:** подключение сервиса к настоящему каталогу MiniProjects, чтобы новые проекты автоматически становились доступны Project Finder.

## Оборудование и инструменты

Компьютер, браузер, среда разработки, AI-кодовый ассистент. Для базовой версии не требуется LLM API. Конкретный стек участники определяют самостоятельно.

## Что предстоит изучить

проектирование веб-приложения; структура и моделирование данных; характеристики объектов; фильтрация; scoring; алгоритмы рекомендаций; пользовательские предпочтения; объяснимость решений; разделение recommendation logic и интерфейса; проектирование пользовательского опроса.

Важное понимание: Recommendation System необязательно начинается с нейросети. Иногда хорошо спроектированных данных и правил достаточно для MVP.

## Полученные навыки

Web Development, алгоритмическое мышление, моделирование данных, проектирование recommendation logic, Product Thinking, UX, работа с пользовательскими предпочтениями, тестирование алгоритмов, AI-assisted development.

## Результат

Работающий веб-сервис, который помогает новому участнику MINILAB выбрать MiniProject и объясняет, почему предложенные проекты могут ему подойти.

## Критерии готовности

Проект завершён, если:
- каталог MiniProjects доступен;
- проекты имеют характеристики;
- пользователь может пройти опрос;
- ответы влияют на результат;
- система выдаёт несколько рекомендаций;
- разные профили пользователей дают разные результаты;
- пользователь понимает причину рекомендации;
- можно открыть карточку выбранного MiniProject;
- участник способен объяснить алгоритм выбора.

Отдельный важный тест: если два человека с принципиально разными интересами получают практически одинаковые рекомендации — recommendation logic требует доработки.

## Demo Day

Демонстрация через двух противоположных пользователей. Первый («люблю данные, хочу работать за компьютером, интересно AI, железо не привлекает») получает AI Judge / Data Analytics / AI Researcher. Второй («хочу собирать руками, люблю физические устройства, хочу видеть движение») получает Mini Rover / Smart Plant / Muscle Controller. Команда показывает, почему алгоритм принял разные решения.
