# 🔥 HOT PROJECT — EEG Interface

## Направление

**Human–Machine Interfaces**

Дополнительные направления: **BCI · Bio Signals · Signal Processing · Data · ML**

## Уровень сложности

**Advanced / Research / HOT PROJECT**

## Срок

4–8 недель

Этот проект — **верхняя точка всего направления**. Не обязательный для каждого потока MINILAB, а доступный при наличии подходящего оборудования и участника, который уже понимает основы сигналов.

---

# Проблема

Для управления компьютером человек обычно должен совершить физическое действие. Но электрическая активность мозга тоже может быть измерена с поверхности головы при помощи EEG. Возникает исследовательский вопрос:

> **Можно ли использовать измеряемую мозговую активность как дополнительный канал взаимодействия человека с компьютером?**

Так появляется область:

> **Brain–Computer Interfaces — BCI.**

EEG Interface не должен продаваться участникам как «Научимся читать мысли». EEG этого не делает. Проект исследует гораздо более реальную задачу:

> **получение EEG → обработка сигнала → выделение воспроизводимых признаков → использование их в простом интерфейсе.**

---

# Задача

Создать **EEG Interface** — экспериментальную BCI-систему, которая получает EEG-сигнал, визуализирует его и исследует преобразование выбранных характеристик сигнала в компьютерную команду.

```text
Brain Activity → EEG Electrodes → Acquisition → Raw EEG → Signal Processing → Features → Detection / Classification → Command → Computer
```

---

# Level 1 — See Your EEG

Первая задача не связана с управлением. Нужно получить реальный EEG-сигнал. На экране — `EEG Stream`. Участник должен разобраться: что именно измеряется, какие используются электроды, почему сигнал настолько слабый, почему появляется шум, как движение головы портит измерения, почему расположение электродов имеет значение. Первый milestone:

> **мы способны стабильно получить и записать EEG.**

---

# Level 2 — Raw vs Processed

Следующий этап — обработка.

```text
Raw EEG → Filtering → Artifact Handling → Processed Signal
```

Участник сравнивает **сырой сигнал** и **обработанный сигнал**. Это принципиально важно: BCI нельзя строить по принципу «подключили электроды и отправили числа в AI».

---

# Level 3 — Frequency Analysis

EEG можно исследовать не только во времени, но и в частотной области: **Time Domain → Frequency Domain**. Участник знакомится с частотой, спектром, FFT, диапазонами активности, окнами анализа и видит, что сигнал описывается набором характеристик.

---

# Level 4 — Controlled Experiment

Система записывает несколько заранее определённых состояний/задач в контролируемых условиях.

```text
Condition A → EEG Recording
Condition B → EEG Recording
```

Задача не объявить «вот сигнал счастья», а проверить:

> **существует ли в выбранной экспериментальной постановке воспроизводимое различие, которое наша система способна обнаружить?**

---

# Level 5 — Classification

Если данные позволяют, строится классификатор (offline): EEG Window → Feature Extraction → Classifier → CLASS_A / CLASS_B. Записанный dataset → обучение → проверка на новых данных. Появляются метрики **Accuracy · Precision · Recall · Confusion Matrix**. Вопрос:

> **Мы действительно нашли закономерность или просто переобучили модель на маленьком датасете?**

---

# Level 6 — Real-Time BCI

Только после offline-проверки классификатор подключается к живому сигналу. Например `SELECT` или `LEFT / RIGHT` — очень ограниченная команда.

---

# Level 7 — BCI Control

Полученная команда подключается к простому интерфейсу. Цель не в количестве команд. Даже **одна устойчиво воспроизводимая BCI-команда** — серьёзный результат.

---

# Level 8 — NeuroControl Integration

Здесь два HOT PROJECT сходятся. EEG становится ещё одним адаптером multimodal **Human–Machine Interface** (EMG, IMU, PPG, EEG → Command Layer → Target System). Например: IMU → Direction, EMG → Action, EEG → дополнительная команда.

---

# Level 9 — BCI Experiment Platform

Продвинутая версия становится платформой: Participant → Experiment → Recording → Dataset → Pipeline → Model → Evaluation → Result. Можно проводить разные исследования и сравнивать способы фильтрации, признаки, классификаторы, расположение сенсоров, окна сигнала и экспериментальные сценарии. Проект превращается почти в маленькую BCI Research Platform.

---

# Очень важная граница

EEG Interface не: **читает мысли; определяет личность; узнаёт, о чём думает человек; диагностирует заболевания; достоверно определяет эмоции по EEG.** Мы измеряем электрическую активность и исследуем **конкретные воспроизводимые паттерны в строго определённом эксперименте**. Это один из главных образовательных результатов:

> **Научиться отличать реальные возможности нейротехнологий от красивого маркетинга вокруг них.**

---

# Данные

Участник получает настоящий небольшой biosignal dataset (`participant_id`, `experiment`, `condition`, `channel`, `timestamp`, `signal`) и поверх него `window_id`, `features`, `label`, `prediction`, `confidence`. EEG Interface одновременно становится серьёзным **Data Project**.

---

# Что предстоит изучить

Основы нейрофизиологии, EEG, электроды, sampling rate, time-series, noise, artifacts, digital filtering, frequency analysis, FFT, feature extraction, datasets, experiment design, classification, validation, ML, real-time processing, BCI, Human–Machine Interaction.

---

# Полученные навыки

EEG Acquisition, Biosignal Processing, Digital Signal Processing, Experimental Design, Time-Series Analysis, Feature Engineering, Machine Learning, BCI и Human–Machine Interfaces. Главный навык:

> **умение пройти весь путь от слабого физического сигнала человеческого тела до проверяемой компьютерной команды — и доказать данными, что система действительно работает.**

---

# Результат

Минимальный **EEG Interface v0.1**: **EEG → Recording → Processing → Visualization → Experiment**. Продвинутая версия: **EEG → Processing → Features → Classification → Command → Interface**. Отсутствие устойчивой классификации не обязательно означает провал — корректно проведённый честный эксперимент, показавший результат не лучше случайного уровня, тоже является исследовательским результатом и важным уроком для HOT PROJECT.

---

# Критерии готовности

**Базовый уровень:** реальное EEG-оборудование; запись сигнала; сохранение сырых данных; визуализация; воспроизводимый экспериментальный протокол; объяснение источников артефактов; обработанные данные не подменяют исходные; результаты сохраняются; выводы соответствуют данным.

**Полная HOT-версия:** размеченный dataset; признаки; классификатор; отдельная проверочная выборка; метрики; confusion matrix; оценка относительно baseline; классификация с живым потоком; минимум одна команда управляет внешним интерфейсом.

---

# Demo Day

Участник надевает EEG-устройство. На большом экране одновременно: **RAW EEG → FILTERED EEG → FEATURES → CLASSIFICATION → COMMAND**. Никакой заранее записанной магии. После калибровки система получает окно EEG, обрабатывает его, классификатор выдаёт результат, и если экспериментальная схема позволяет — на втором экране происходит действие. Даже если это всего лишь `SELECT`, это сильная демонстрация:

> **человек → мозговая активность → электрический сигнал → данные → математика → алгоритм → команда → машина.**

EEG Interface — финальный проект не только направления Human–Machine Interfaces, но потенциально один из самых сложных HOT PROJECT всего MINILAB.
