# 🔥 HOT PROJECT — TAIL HAND

> **Направление:** Assistive Tech & Протезирование
> **Дополнительные направления:** Bio Signals · Robotics · Embedded Systems · 3D Printing · HCI
> **Уровень сложности:** Advanced / HOT PROJECT
> **Срок:** 4–6 недель для первой полноценной версии

## Статус HOT PROJECT

**TAIL HAND** — один из наиболее сложных MiniProjects трека MINILAB. Участник собирает целую физическую систему:

> **мышца человека → биосигнал → обработка → команда → электроника → механика → движение**

Цель MINILAB — **не создать медицинский протез**, а создать **исследовательский прототип роботизированной кисти, которой человек способен управлять посредством собственной мышечной активности**.

## Задача

Создать **TAIL HAND** — 3D-печатный прототип роботизированной кисти, способной выполнять движения на основании сигнала EMG.

```text
Human → Muscle Activity → EMG Sensor → Raw Signal → Signal Processing → Command → Controller → Actuators → Mechanical Hand
```

В минимальной версии: сокращение мышцы → кисть закрывается; возврат/другая команда → кисть открывается.

## Основная инженерная задача

> **Как преобразовать мышечную активность человека в управляемое движение механической кисти?**

## Этапы развития

1. **Mechanical Hand** — доказать, что кисть способна двигаться (Servo→Tendon→Finger Joint→Finger Movement).
2. **Programmatic Control** — `OPEN_HAND` / `CLOSE_HAND` через контроллер.
3. **First EMG Signal** — увидеть собственную мышечную активность как цифровые данные.
4. **Signal Processing** — Filtering → Feature → Threshold / Classifier → Command.
5. **EMG → HAND** — первый сквозной milestone: человек сжимает мышцу → кисть закрывается.
6. **Personal Calibration** — индивидуальный baseline и пороги для конкретного пользователя.
7. **Multiple Commands** — классификация нескольких управляющих состояний (OPEN / CLOSE / PINCH).
8. **Grip System** — высокоуровневые действия: Power Grip, Pinch, Point, Open Hand.
9. **Smart Grip** — датчики давления / силы / касания / положения.
10. **Closed-Loop Control** — поддержание требуемого усилия автоматически (Control Systems).
11. **Feedback to Human** — искусственная чувствительность (Haptic Feedback): Force Sensor → Haptic Motor → Human.
12. **TAIL HAND Intelligence** — адаптация / распознавание паттернов. **LLM не должна находиться в real-time control loop кисти** — низкоуровневое управление остаётся детерминированным.

## Архитектура (развитая версия)

```text
HUMAN → BIO INPUT (EMG) → SIGNAL SYSTEM (processing/calibration/recognition) → MOTION SYSTEM (grips/actuators/control) → MECHANICAL HAND → OBJECT → FEEDBACK (force/touch) → HUMAN
```

## Разделение ответственности

- **EMG Sensor** — измеряет физический сигнал.
- **Signal Processor** — преобразует сырые измерения в признаки.
- **Recognizer** — определяет управляющее состояние.
- **Motion Controller** — решает, как выполнить команду.
- **Actuators** — создают физическое движение.
- **Mechanical Hand** — взаимодействует с объектом.
- **Force/Touch Sensors** — измеряют результат взаимодействия.
- **Haptic System** — возвращает часть информации человеку.

## Что НЕ является целью

TAIL HAND не должен стать полноценным медицинским протезом, устройством для постоянного ношения, заменой сертифицированным протезам, системой медицинской диагностики или универсальной кистью. Это **исследовательский инженерный прототип**.

## Командный формат

Рекомендуется небольшая команда:

- **Hardware / Embedded** — EMG, электроника, контроллеры.
- **Mechanical** — кисть, суставы, приводы, 3D-печать.
- **Software / Signals** — обработка EMG, калибровка, распознавание.
- **Data / ML** (при развитии) — датасет и классификация паттернов.

Архитектуру системы команда проектирует совместно.

## Что предстоит изучить

Анатомия мышечного сокращения, EMG, электрические сигналы, аналоговые измерения, ADC, noise, filtering, signal processing, thresholding, calibration, feature extraction, classification, embedded development, сервоприводы, механические передачи, 3D-моделирование, 3D-печать, sensors, feedback loops, основы Control Systems, Haptic Feedback.

На продвинутом уровне: **Machine Learning · Pattern Recognition · Adaptive Control**.

## Полученные навыки

Embedded Systems, Robotics, Biosignal Processing, EMG, Signal Processing, Hardware–Software Integration, Mechanical Design, 3D Printing, Control Systems, основы бионических интерфейсов.

Главный навык: **умение построить систему, соединяющую человеческое тело, программное обеспечение и физический механизм в едином контуре управления**.

## Результат

Работающий **TAIL HAND v0.1** — исследовательский прототип механической кисти, способной выполнять минимум одно управляемое движение на основе измеренной мышечной активности.

Минимальная цепочка: Muscle → EMG → Processing → Command → Controller → Hand.

Продвинутая: Human → EMG → Recognition → Grip → Hand → Object → Sensor → Feedback → Human.

## Критерии готовности (базовая HOT-версия)

- существует физическая механическая кисть;
- основные элементы изготовлены/собраны командой;
- кисть программно открывается и закрывается;
- используется реальный EMG-сенсор;
- можно увидеть и записать сырой сигнал;
- состояние покоя различается от выбранного мышечного сокращения;
- реализована обработка сигнала;
- существует персональная калибровка;
- EMG действительно управляет физическим движением кисти;
- проведена серия повторных испытаний;
- результаты испытаний зафиксированы;
- ошибка распознавания не скрывается;
- участники могут объяснить полный путь сигнала от мышцы до движения пальцев.

Главная проверка: если заменить EMG обычной кнопкой, команда понимает, какую часть системы заменила и почему остальное работает.

## Demo Day

На стенде: TAIL HAND + график EMG. Калибровка → живой сигнал → `CLOSE_HAND` (кисть закрывается вокруг предмета) → `OPEN_HAND`. В продвинутой версии: кисть берёт предмет, датчик фиксирует контакт, система ограничивает усилие, пользователь получает тактильный сигнал.

> **Программирование здесь больше не заканчивается экраном. Код получает сигнал от человеческого тела — и превращает его в движение физического объекта.**
