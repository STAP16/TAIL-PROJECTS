# Virtual College

**Направление:** Game Development
**Дополнительные направления:** 3D · Level Design · Interactive Experience · Digital Twin
**Уровень сложности:** Продвинутый
**Срок:** 2–3 недели для MVP одного участка колледжа

## Проблема

До поступления абитуриент знает колледж в основном по сайту, фотографиям, социальным сетям и дням открытых дверей. Но фотографии плохо передают пространство. Человеку сложно понять:

> Как колледж выглядит внутри? Как устроены корпуса и этажи? Какие здесь аудитории и лаборатории? Где учатся студенты? Какая вообще атмосфера внутри?

Чтобы нормально познакомиться с пространством, обычно приходится приезжать лично. Для абитуриента из другого района или города это особенно неудобно. Возникает идея:

> **Дать человеку возможность зайти в колледж ещё до того, как он физически туда приехал.**

## Задача

Создать **Virtual College** — интерактивную виртуальную модель реального колледжа, по которой пользователь может свободно перемещаться. Это не набор 360°-фотографий и не видеоролик с экскурсией. Пользователь сам управляет персонажем или камерой:

**входит в здание → идёт по коридору → поднимается на этаж → заходит в аудиторию → осматривает лабораторию → взаимодействует с объектами.**

Базовый цикл: **Explore → Discover → Interact → Learn**

> **Не показать колледж человеку. Дать ему самому по нему пройтись.**

## Описание

За основу берётся **реальное пространство колледжа**. Команда сначала должна его исследовать: планировка, этажи, коридоры, лестницы, основные помещения, аудитории, лаборатории, заметные ориентиры. После этого создаётся виртуальная версия. Для MVP разумно выбрать ограниченную область: вход + один этаж + несколько ключевых помещений.

## Реальный колледж как источник требований

Команда не придумывает уровень полностью из головы. Само здание становится источником требований. Перед разработкой собираются материалы: фотографии → размеры → расположение → ориентиры → особенности пространства. Это хороший первый опыт работы с реальным объектом, который необходимо перенести в цифровую среду.

## Минимальные требования (MVP)

* виртуальная модель части реального колледжа;
* свободное перемещение;
* несколько связанных помещений;
* понятная навигация;
* возможность заходить хотя бы в часть помещений;
* узнаваемые элементы реального пространства;
* несколько интерактивных точек;
* информация о выбранных помещениях;
* начало и завершение виртуального маршрута.

Пользователь не должен постоянно читать инструкции, чтобы понять, куда идти и как взаимодействовать.

## Возможное развитие

### Level 2 — Interactive Points
Интерактивные объекты. Пользователь подходит к лаборатории → появляется «Лаборатория робототехники» и [Узнать подробнее]: назначение, оборудование, фотографии, проекты, видео. **Physical Space → Virtual Object → Information**

### Level 3 — Navigation
Пользователь выбирает «Найти библиотеку» / «Найти аудиторию 305» → система показывает маршрут. **Current Position → Destination → Route**

### Level 4 — Multiple Floors
Лестницы, несколько этажей, переходы, дополнительные помещения. Полноценная задача **Level Design**: пространство должно соответствовать реальному зданию и оставаться понятным для человека, который здесь никогда не был.

### Level 5 — Guided Tour
Режим экскурсии («Свободная прогулка» / «Экскурсия»). Система предлагает маршрут (Вход → Аудитории → Лаборатории → Библиотека → TAIL → Завершение), но пользователь перемещается самостоятельно и может отклониться.

### Level 6 — Specialty Tour
Маршруты под конкретный интерес абитуриента. «Покажи, где учатся студенты специальности X» → тематический маршрут (аудитория → компьютерный класс → лаборатория → проектная зона). Помогает понять образовательную среду.

### Level 7 — POLY Inside Virtual College
Внутри виртуального колледжа размещается POLY (персонаж или терминал): «Что находится на этом этаже?», «Где здесь лаборатория?». Архитектура: Player → Virtual College → POLY Interface → POLY Backend → Knowledge / Tools. GameDev-проект не создаёт второго POLY, а создаёт ещё один интерфейс к существующей системе.

### Level 8 — Context-Aware POLY
Игра сообщает POLY, где находится пользователь (location: floor_3, room: robotics_lab). POLY отвечает относительно текущего пространства. **Game State + User Question → POLY → Contextual Answer**

### Level 9 — Real-Time Information
Виртуальный информационный экран показывает ближайшие мероприятия, новости, информацию TAIL, объявления. **Backend Data → API → Virtual Object**

### Level 10 — Digital Twin
Движение от виртуальной экскурсии к элементам Digital Twin. Virtual College: «Вот как выглядит пространство». Digital Twin: «Вот что происходит в пространстве сейчас». Для MINILAB это не требование, а возможное направление дальнейшего исследования.

## Как собирать модель колледжа

### Ручное моделирование
Команда самостоятельно создаёт помещения и основные объекты. Полный контроль, но много работы.

### Фотограмметрия / 3D Scan
Реальное помещение сканируется с помощью фотографий или средств пространственного сканирования, затем оптимизируется.

### Гибрид (наиболее практичный)
Геометрия создаётся относительно просто, а узнаваемость достигается за счёт реальных текстур, фотографий, характерных объектов, вывесок, мебели, интерьера. Для MVP не нужна миллиметровая копия — важно, чтобы человек, бывавший в помещении, узнал это место.

## Оптимизация

Подробная 3D-модель может быть слишком тяжёлой, особенно при запуске через браузер. Инженерные решения: упрощать геометрию, оптимизировать текстуры, ограничивать дальность отображения, загружать части пространства по мере необходимости.

## Career Quest и Virtual College (разграничение)

**Career Quest**: «Как может выглядеть мой путь обучения?» — сюжетная пиксельная игра (Story → Quest → Progression).

**Virtual College**: «Как выглядит и устроен сам колледж?» — исследование пространства (Space → Exploration → Navigation).

Они остаются самостоятельными GameDev MiniProjects.

## Потенциал для колледжа

Использование: на сайте колледжа, при поступлении, перед днём открытых дверей, для удалённого знакомства, на презентациях и выставках. Virtual College снижает барьер **до первого посещения**, но не заменяет реальное посещение.

## Что предстоит изучить

основы GameDev; 3D-пространство; координаты; управление камерой/персонажем; collision; Level Design; 3D-моделирование; материалы и текстуры; освещение; интерактивные объекты; UI внутри игрового пространства; оптимизацию; работу с референсами; основы фотограмметрии/3D-сканирования; навигацию; проектирование пользовательского маршрута.

При расширении: **API Integration · POLY Integration · Digital Twin concepts**

## Полученные навыки

Game Development, 3D, Level Design, Environment Design, Navigation, Interaction Design, оптимизация графики и работа с реальным пространством как источником требований. Особенно интересный навык — **перевод физического пространства в цифровую интерактивную модель**.

## Результат

Работающий **Virtual College v0.1** — интерактивная виртуальная модель части реального колледжа, по которой пользователь может самостоятельно перемещаться и исследовать основные помещения.

Минимальный цикл: **Enter → Explore → Discover → Interact**

## Критерии готовности

* существует виртуальная модель выбранной части колледжа;
* её структура основана на реальном пространстве;
* пользователь свободно перемещается;
* помещения связаны между собой;
* присутствуют узнаваемые ориентиры;
* минимум несколько объектов интерактивны;
* пользователь может получить информацию о помещении;
* навигация понятна человеку, который раньше здесь не был;
* приложение работает с приемлемой производительностью;
* участник способен объяснить, какие части пространства воспроизведены точно, а какие сознательно упрощены.

## Demo Day

Человеку дают управление: «Ты никогда здесь не был. Попробуй найти лабораторию TAIL». Пользователь входит в виртуальный колледж, идёт по холлу и коридорам, поднимается на этаж, заходит в помещения, находит лабораторию, взаимодействует со стендом и узнаёт о проектах. Если реализован POLY Level: «POLY, а как попасть в эту лабораторию?». После рядом показывается реальный план/фотография участка — видно, насколько модель соответствует пространству. Главный результат проверяется вопросом: если человек никогда не был в колледже, станет ли это место для него хоть немного знакомым после десяти минут в Virtual College?
