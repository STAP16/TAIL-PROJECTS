# Smart Demo Stand

> **Направление:** Arduino & Robotics
> **Дополнительные направления:** Physical Computing · Human–Machine Interaction · IoT
> **Уровень сложности:** Средний
> **Срок:** 1–2 недели

Интерактивный демонстрационный стенд, который сам замечает посетителя и запускает понятную интерактивную демонстрацию проекта.

## Проблема

На выставках, днях открытых дверей, Demo Day и презентациях проекты часто показываются через обычный экран, плакат или ноутбук. Такой стенд пассивен:
- не понимает, подошёл ли человек;
- не умеет сам начать демонстрацию;
- не подстраивает сценарий под взаимодействие;
- требует, чтобы рядом постоянно находился участник команды.

Вопрос: можно ли сделать стенд, который сам замечает посетителя и запускает понятную интерактивную демонстрацию проекта?

## Задача

Создать интерактивный демонстрационный стенд, реагирующий на присутствие человека и управляющий последовательностью показа.

**Базовый цикл:** `Visitor → Sensor → Event → State Machine → Light / Display / Sound / Physical Action`

Устройство должно не просто включать лампочку при движении, а иметь продуманное поведение во времени.

## Описание

В обычном состоянии Smart Demo Stand находится в режиме ожидания.

- **IDLE** — экран показывает название проекта, подсветка работает спокойно.
- **PERSON_DETECTED** — когда человек подходит, стенд меняет состояние и привлекает внимание: «Привет! Хочешь посмотреть, как работает Physical POLY?»
- **WELCOME → DEMO** — запускается демонстрационный сценарий (видео, анимация, движение механизма, включение другого устройства, голосовое объяснение, последовательность физических действий).
- **FINISH → IDLE** — стенд возвращается в исходное состояние и готов к следующему посетителю.

**Пример State Machine:** `IDLE → PERSON_DETECTED → WELCOME → DEMO → FINISH → IDLE`

> Главная инженерная задача — спроектировать сценарий взаимодействия, а не просто подключить датчик движения.

## Минимальные требования

Первая версия должна:
- определять присутствие человека;
- иметь минимум три различных состояния;
- менять поведение в зависимости от состояния;
- запускать демонстрацию автоматически или после подтверждения пользователя;
- использовать минимум два способа физической обратной связи;
- завершать сценарий;
- возвращаться в режим ожидания;
- корректно обрабатывать ситуацию, когда посетитель ушёл до конца демонстрации.

Например: `Sensor + LED + Display` или `Sensor + Sound + Servo`. Конкретный сценарий проектирует участник.

## Возможное развитие

- **Level 2 — Interactive Start:** не начинать демонстрацию сразу. Стенд спрашивает «Запустить демонстрацию?», пользователь нажимает кнопку/сенсор. `Detection → Invitation → Human Action → Demo`. Обнаружить человека и получить согласие — разные события.
- **Level 3 — Multi-Step Demo:** показ разбивается на этапы (что за проект → какую проблему решает → как работает → живая демонстрация → QR/следующий шаг). Посетитель переходит дальше сам.
- **Level 4 — Visitor Interaction:** выбор сценария («Как работает», «Попробовать самому», «Узнать про TAIL»). Ветвящаяся State Machine.
- **Level 5 — Device Integration:** стенд управляет другим MiniProject ([[Physical POLY - Физическая оболочка POLY|Physical POLY]], [[Talking Plant - Говорящее растение|Talking Plant]]). Стенд становится оркестратором демонстрации другого устройства.
- **Level 6 — POLY Integration:** POLY как интеллектуальный слой. `Visitor → Smart Demo Stand → POLY → Selected Demo → Physical Device`. Вместо фиксированного меню — естественный язык.
- **Level 7 — Demo Analytics:** сбор данных о взаимодействиях (сколько людей подошло, сколько запустило, какой сценарий, сколько досмотрело, время). `Physical Interaction → Events → Data → Analytics`.
- **Level 8 — Multiple Projects:** единый стенд для нескольких направлений TAIL (POLY, MINILAB, AI Agents, Robotics). Полноценный интерактивный выставочный терминал TAIL.

## Потенциал развития в TAIL

Использование: Demo Day, набор в MINILAB, дни открытых дверей, выставки, чемпионаты, презентации TAIL, стенд лаборатории внутри колледжа. Особенно интересен сценарий, при котором стенд не разбирают после MINILAB — следующие команды добавляют новые демонстрационные модули. Первая версия создаёт платформу, а не одноразовую инсталляцию.

## Оборудование и инструменты

Базовая версия: Arduino или ESP32, датчик присутствия/расстояния, LED или адресная подсветка, небольшой экран, кнопка или touch-сенсор, динамик, сервопривод, макетная плата, провода, корпус/стенд.

Расширенные версии: камера, микрофон, дополнительные дисплеи, сетевое подключение, интеграция с POLY API, другие устройства TAIL.

## Что предстоит изучить

Arduino/ESP32, датчики, события, State Machine, таймеры, обработка пользовательского ввода, сервоприводы, дисплеи, звук, Human–Machine Interaction, проектирование пользовательского сценария, Hardware–Software Integration, основы IoT, при расширении — API и AI-интеграции.

> Главная концепция: физический продукт должен проектироваться не только как схема компонентов, но и как последовательность поведения. Участник отвечает не только «Какие датчики подключить?», но и «Что устройство должно делать в каждый момент взаимодействия с человеком?»

## Полученные навыки

Physical Computing, Arduino/ESP32, State Machines, Event-Driven Thinking, Interaction Design, Hardware–Software Integration, работа с сенсорами и исполнительными устройствами.

## Результат

Работающий Smart Demo Stand v0.1, способный обнаружить посетителя, запустить интерактивный сценарий демонстрации и корректно вернуться в исходное состояние.

**Минимальный цикл:** `Person → Detection → Welcome → Demo → Finish → Reset`

## Критерии готовности

Проект завершён, если:
- стенд обнаруживает человека;
- существует минимум три состояния;
- переходы между состояниями работают;
- пользователь получает понятную обратную связь;
- демонстрационный сценарий действительно запускается;
- сценарий завершается;
- устройство самостоятельно возвращается в IDLE;
- уход пользователя во время демонстрации обработан;
- участник способен нарисовать State Machine своего стенда;
- участник способен объяснить, почему система находится в каждом из состояний.

## Demo Day

Стенд находится в режиме `IDLE`. Человек подходит, срабатывает датчик, устройство переходит в `PERSON DETECTED`: включается подсветка, на экране «Привет! Хочешь посмотреть проект?». Пользователь подтверждает — начинается `DEMO` (экран, движение, звук или другое устройство). После завершения «Спасибо!» и стенд возвращается в `IDLE`.

При интеграции с другим проектом финальная демонстрация может быть особенно сильной: человек подходит → стенд активируется → предлагает познакомиться с POLY → запускается Physical POLY.

> Smart Demo Stand — это не датчик движения с подсветкой. Это физическая система, которая управляет целым сценарием взаимодействия с человеком.
