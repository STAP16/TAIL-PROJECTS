# TAIL Grants Radar

**Направление:** Data & Analytics
**Дополнительное направление:** AI & Agents
**Уровень сложности:** Средний
**Срок:** 2 недели

## Проблема

Для TAIL и студенческих технологических проектов существует множество возможностей внешнего финансирования: грантовые конкурсы, программы поддержки, акселераторы и другие инициативы.

Информация о них находится на разных сайтах и постоянно обновляется. Чтобы найти подходящую возможность, необходимо вручную отслеживать источники, читать условия, проверять сроки и сопоставлять требования конкурса с конкретным проектом.

В результате подходящий конкурс легко обнаружить слишком поздно или пропустить полностью.

## Задача

Создать систему, которая собирает информацию о грантовых конкурсах из нескольких источников, приводит её к единой структуре, анализирует и помогает определить, какие возможности подходят TAIL и его проектам.

## Описание

TAIL Grants Radar — внутренний инструмент мониторинга внешнего финансирования для лаборатории.

Система получает информацию о грантовых конкурсах и программах поддержки из доступных источников.

Каждый найденный конкурс проходит обработку:

Источник → Сбор → Извлечение данных → AI-анализ → Структурированные данные → Аналитика

Из обычной страницы конкурса необходимо получить, например:

- название;
- организатора;
- размер финансирования;
- дату окончания приёма заявок;
- требования к участникам;
- направления конкурса;
- требования к проекту;
- ссылку на первоисточник.

После обработки информация попадает в единый каталог и календарь.

Пользователь может увидеть ближайшие дедлайны, доступные программы и распределение возможностей по направлениям.

Дополнительно AI может сопоставлять условия конкурса с описанием конкретного проекта TAIL.

Например:

> Подходит ли «Студенческий стартап» для [[POLY - AI ассистент|POLY]]?

Система анализирует две сущности:

Требования конкурса ↔ Характеристики проекта

и формирует объяснимый результат:

- **Высокое соответствие**
- Подходящие критерии: AI-направление, студенческий проект, наличие прототипа.
- Требует проверки: условия участия заявителя.
- Дедлайн: ...

AI не должен самостоятельно придумывать отсутствующие условия конкурса. Решение должно опираться на собранные данные и сохранять связь с первоисточником.

## Минимальные требования

- сбор информации минимум из нескольких заданных источников;
- сохранение ссылки на первоисточник;
- приведение разных конкурсов к единой структуре;
- извлечение основных условий конкурса;
- использование AI для обработки неструктурированного текста;
- каталог найденных возможностей;
- отображение ближайших дедлайнов;
- календарное представление;
- фильтрация конкурсов;
- базовая аналитика по собранным данным;
- возможность обновлять информацию без ручного пересоздания всей базы.

## Возможное развитие

**Level 2 — Deadline Analytics.** Аналитика календаря: количество дедлайнов по неделям и месяцам, наиболее загруженные периоды, ближайшие конкурсы, завершённые конкурсы, время до подачи заявки.

**Level 3 — Project Matching.** Добавить проекты TAIL в систему: POLY → 86%, [[TAIL Analytics|TAIL Analytics]] → 71%.

**Level 4 — AI Grant Analyst.** AI-агент поверх базы: «Какие гранты сейчас подходят POLY?», «Что заканчивается в ближайшие 30 дней?», «Какие требования необходимо выполнить для подачи?».

**Level 5 — Notifications.** Автоматические предупреждения: через 30 дней заканчивается приём заявок, появился новый подходящий конкурс.

**Level 6 — Grant Pipeline.** Трекинг заявки: Найден → Анализируется → Решили участвовать → Подготовка → Подано → Результат.

## Оборудование и инструменты

Специальное оборудование не требуется. Необходимы компьютер, доступ к открытым источникам информации, AI-модель/API и инструменты для разработки и анализа данных. Конкретный инженерный стек заранее не задаётся.

## Что предстоит изучить

- сбор данных из нескольких источников;
- парсинг веб-данных;
- неструктурированные и структурированные данные;
- проектирование единой модели данных;
- очистка и нормализация;
- извлечение информации с помощью LLM;
- structured output;
- работа с датами и дедлайнами;
- дедупликация;
- аналитические метрики;
- data pipeline;
- основы recommendation/matching logic;
- работа AI-агента поверх собственной базы данных.

Важная идея проекта: **AI работает не вместо данных — AI становится одним из этапов их обработки и анализа.**

## Полученные навыки

Data Collection, Data Engineering, Data Analytics, работа с внешними источниками, проектирование data pipeline, LLM Extraction, Structured Output, аналитическое мышление, визуализация данных, основы AI Agents и построение AI-функций поверх собственной базы.

## Результат

Работающий TAIL Grants Radar, который собирает информацию о грантовых возможностях, приводит её к единому формату и позволяет TAIL видеть доступные программы финансирования, ближайшие дедлайны и потенциальное соответствие конкурсов проектам лаборатории.

## Критерии готовности

Проект считается завершённым, если:

- данные собираются минимум из нескольких источников;
- конкурсы сохраняются в единой структуре;
- для каждой записи сохраняется первоисточник;
- AI способен извлекать основные параметры из неструктурированного описания;
- пользователь видит актуальный каталог;
- дедлайны отображаются в календаре;
- доступны базовые фильтры;
- система показывает хотя бы несколько аналитических показателей;
- повторное получение одного конкурса не создаёт бесконтрольные дубликаты;
- участник способен объяснить весь путь данных от источника до аналитического интерфейса.

## Demo Day

Показать полный цикл на реальном примере:

Источник гранта → получение страницы → обработка → AI Extraction → структурированная запись → Grants Radar → календарь/аналитика.

Затем выбрать один проект TAIL и продемонстрировать, как система помогает ответить на вопрос:

> «Подходит ли этот грантовый конкурс нашему проекту и почему?»

Участник должен отдельно объяснить, какие части результата получены непосредственно из источника, какие рассчитаны системой, а какие сформированы AI.
